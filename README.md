# Flateka

Site da Flateka, consultoria digital para pequenas e médias empresas de Nova Iguaçu e região.

## Páginas

- Início
- Serviços
- Planos
- Avulsos (configurador de placas)
- Exemplos
- Contato

## Tecnologias

- HTML, CSS e JavaScript
- GSAP e ScrollTrigger para as animações
- Lenis para a rolagem suave
- WebGL no fundo animado
- Firebase Hosting

## Como editar

As páginas são geradas pelo arquivo `build/build.py`. Depois de alterar textos, preços ou fotos, rode:

```
python3 build/build.py
```

Cada push na branch `main` publica o site automaticamente.
